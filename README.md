# Saumya Singh | Personal Portfolio

## Description
This is my **personal portfolio website**, showcasing my skills, projects, and accomplishments as an aspiring **AI and Web Developer**. It highlights my educational background, professional experience, and hands-on projects built with HTML, CSS, JavaScript, Node.js, and AI/ML basics.

## Features
- **Home Page**: Captivating headline, professional photo, and summary of skills  
- **About Me**: Detailed background, education, and career goals  
- **Projects**: Showcase of web and AI projects including College Event Tracker, KissanMitra, Tic-Tac-Toe, Stopwatch, and Complaint Management System  
- **Skills**: Frontend, backend, AI/ML, DSA, and problem-solving skills  
- **Contact**: Email, GitHub, and LinkedIn links for networking and collaboration  

## Technologies Used
- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Node.js, MongoDB (for some projects)  
- **AI/ML**: Python, basic AI/ML models and experimentation  
- **Other**: Git & GitHub for version control  

## How to Run
1. Clone or download the repository.  
2. Open the `index.html` file in a browser to view the portfolio.  
3. Navigate through sections to explore **Home, About Me, Projects, Skills, and Contact**.
